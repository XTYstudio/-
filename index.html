样本与解释边界

这是目的性样本：按“数据分析、商业分析、数据产品或 AI 数据工作流相关”筛选公开岗位，不是随机抽样。它跨公司、地区、招聘类型和经验级别，不能代表整个中国岗位市场或应届岗位市场。发布日期未标注时保留为未标注，页面更新时间单独记录。第三方聚合来源与雇主官方页面分开标记；当前申请状态需要回原页核实。
技能比例 = 至少提到该技能的不同岗位数 ÷ 当前筛选后的岗位数。脚本按关键词初筛，人工抽查与修正规则记录在 README 和 audit_log.csv。
新增岗位：填写 data/new_postings.csv 中的字段后运行 scripts/update_dashboard.py。该脚本按明示关键词生成候选标签并刷新看板，不会自动联网抓取，也不是自主 Agent。
